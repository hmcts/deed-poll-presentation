# Deed Poll presentation

Branded overview and presenter notes for the October 2026 AAT demonstration.

## Read on another machine

```sh
git clone https://github.com/hmcts/deed-poll-presentation.git
cd deed-poll-presentation
```

Open `overview.html` or `demo-script.html` in a web browser. No installation, build or server is needed. For later updates, run `git pull`.

- `overview.html` — attendee overview.
- `demo-script.html` — presenter notes and rehearsal checklist.
- `demo-supporting-document.pdf` — two-page, demonstration-only upload sample linked from the script.
- `artifact-notes.json` — source, branding and rehearsal provenance.

The HTML files embed the branding assets and work offline. Links to AAT require network access and the appropriate signed-in account. The script includes internal rehearsal details; share the overview with attendees.

Copied from the `presentation/` directory of `hmcts/deed-poll-documentation`, presentation branch, at commit `af1d231`.
